# 📋 Configuración y Setup del Proyecto

## 🔧 Stack Actual

- **Backend**: NestJS 10.x
- **Lenguaje**: TypeScript
- **Base de Datos**: PostgreSQL con Prisma ORM
- **Validación**: Zod
- **Documentación**: Swagger UI + OpenAPI JSON
- **Modelo IA**: GPT-5-mini (OpenAI)
